📚 Library System (Java)

Projeto desenvolvido em Java com foco em modelagem orientada a objetos, simulando o funcionamento de um sistema de biblioteca.
A aplicação organiza diferentes tipos de itens (livros, mapas e periódicos) e usuários, utilizando conceitos clássicos de POO para estruturar o código de forma limpa, reutilizável e escalável.

O que esse projeto demonstra:

  - Uso de herança para reaproveitamento de código (Person → Author, Manager, User)
  - Aplicação de interfaces para padronização de comportamentos (ILibraryArtifact)
  - Encapsulamento com controle de acesso aos atributos
  - Manipulação de coleções com List / ArrayList
  - Organização clara e modular do sistema

Estrutura:

  O sistema está dividido em três partes principais:
    - Pessoas: usuários e gerente da biblioteca
    - Artefatos: livros, mapas e periódicos com comportamento comum
    - Biblioteca: responsável pelo gerenciamento dos dados

Funcionalidades:

  - Cadastro de usuários e gerente
  - Registro de diferentes tipos de itens
  - Verificação de disponibilidade para empréstimo
  - Consulta estruturada dos dados

Objetivo:

  Praticar e consolidar conceitos fundamentais de Programação Orientada a Objetos em Java, com foco em organização, reutilização de código e modelagem de sistemas.

Tecnologias:
- Java 21
- Programação Orientada a Objetos
